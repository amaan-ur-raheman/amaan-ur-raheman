## Things I've built

### [NightCode](https://github.com/amaan-ur-raheman/nightcode)
A terminal-native AI coding assistant. It brings multi-provider model support, PLAN and BUILD modes, tool execution, subagent orchestration, MCP, and Git workflows into one terminal-based development environment.

`TypeScript` `Bun` `Hono` `PostgreSQL` `Prisma` `Vercel AI SDK`

### [CodeSheriff](https://github.com/amaan-ur-raheman/codesheriff)
An AI-assisted GitHub code review system that uses repository context to review pull requests. The workflow combines webhook processing, codebase retrieval, RAG, and sandboxed validation of suggested changes.

[Live demo](https://codesheriff.amaanurraheman.qzz.io/) · `TypeScript` `Next.js` `PostgreSQL` `Prisma` `Pinecone` `Inngest`

### [Resonance](https://github.com/amaan-ur-raheman/resonance)
An AI voice-generation application built around Chatterbox TTS. The project connects a web application to GPU-hosted inference, with voice management, generation history, authentication, storage, and subscription workflows.

`TypeScript` `Next.js` `PostgreSQL` `Prisma` `Python` `FastAPI` `Modal` `Cloudflare R2`

### [ContextSense AI](https://github.com/amaan-ur-raheman/contextsense-ai)
An educational word-sense-disambiguation project. It compares lexical information from WordNet with embedding-based semantic similarity, and includes a playground and evaluation workflow using annotated data.

`Python` `WordNet` `NLTK` `Sentence Transformers` `Word2Vec` `scikit-learn` `Streamlit`
